## ✨ Website ucapan wisuda

## 🚀 Quick start

1. **Buka project**

   Buka folder project di editor pilihan Anda.

2. **Buka dengan Live Server**

   Jalankan `index.html` menggunakan ekstensi Live Server.

3. **Sesuaikan ucapan**
   
   Ubah nama, pesan, foto di folder `img`, atau musik di folder `music` sesuai kebutuhan.

4. **Deploy ke Netlify**
   
   Deploy folder project ke [Netlify](https://www.netlify.com/).
